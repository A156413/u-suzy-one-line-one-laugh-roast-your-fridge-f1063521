Entry for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty — one line, at most 200 characters, roasting the fridge.

## The line

> My fridge hums all night like it's keeping a secret, yet the only thing it has ever preserved is the takeout I forgot in 2023.

## Run

```sh
python3 main.py
```

This prints the line and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with mode `0644`. Python standard library only; no dependencies.
